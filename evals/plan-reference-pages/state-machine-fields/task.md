"Our bookings app needs a workflow.
1. A booking starts as Requested. Staff confirm it or decline it. A confirmed booking can be cancelled, and a declined booking can be requested again.
2. Record when a booking was confirmed.
3. When a booking is declined we need the reason, and it must not be left blank.
4. The bookings list should show only bookings that are still waiting for an answer.
5. When staff decline a booking, record when they declined it, and flag the booking for a follow-up phone call.
6. Add three example bookings: one waiting, one confirmed, one declined.
7. Staff should be able to confirm a booking from its page."
