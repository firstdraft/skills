"Our team tasks app needs sensible starting values so people type less.
1. A new task is not done until someone ticks it off.
2. Each task has a priority, Low, Normal, or High. New tasks are Normal.
3. Each task has a budget in US dollars. It starts at $25.00 unless someone enters another amount.
4. Record the day a task was opened. It should be today unless the person creating it picks another day.
5. Record the exact moment each task was logged, without asking anyone, and never let it change afterwards.
6. Add a due date that starts one week after the day the task was opened.
7. Each task should be assigned to whoever creates it."
