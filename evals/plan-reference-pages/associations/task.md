"Our projects app needs related records on its pages.
1. A project's page should list the project's tasks, and people should be able to add a task right from there.
2. Also on the project's page, show a separate list of just the tasks that aren't done yet.
3. Projects can carry tags, like 'Marketing' or 'Q3', and one tag can be on many projects. People should be able to
   see the list of tags, create a tag, and rename it. From a project's page, people add an existing tag to the project,
   and the project's page shows its tags.
4. A tag's page should list the projects that have that tag.
5. The same tag should never be on one project twice.
6. A project can never have more than 20 tasks.
7. Next to each tag on a project's page, put a Remove button that takes the tag off the project."
