"Our workshops app needs some rules so bad data can't get in.
1. A workshop code is 4 to 8 characters, only capital letters and digits, and no two workshops can share a code.
2. In-person workshops must have a room. Online workshops must not have a room filled in.
3. If a capacity is given, it has to be between 1 and 200.
4. A workshop can't end before it starts.
5. An instructor can't teach two in-person workshops that start on the same day. Online ones don't count.
6. The codes TEST and DEMO are reserved; nobody can use them.
7. Nobody should be able to schedule a workshop in the past."
